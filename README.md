# Aura

**Rich Presence hub for Discord.**

Aura runs in the background and shows what you're doing in other apps as your Discord status. Each app is supported by a plugin, installed from Aura's Marketplace tab. The official plugins, such as Stremio and AniList Sync, live in [AuraPlugins](https://github.com/Nyakaze/AuraPlugins); anyone can host more in a repo of their own. To build one, see [docs/PLUGINS.md](docs/PLUGINS.md).

Status: early development. See [docs/PLAN.md](docs/PLAN.md) for the design.
